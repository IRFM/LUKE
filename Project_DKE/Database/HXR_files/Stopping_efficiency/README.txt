The binary file stopping_efficiency_MEHXR.mat contains the stopping efficiency curve as a function of the energy for the ME-HXR.
It is the combination of the transmission curve of the vacuum window (1 mm Al) and the absorption curve of the CdTe sensor (1 mm CdTe). Both curves are calculated using the code XOP (https://www.esrf.fr/Instrumentation/software/data-analysis/xop2.4)
