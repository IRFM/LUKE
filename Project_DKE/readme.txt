This is a short tutorial to run the 3-D drift kinetic solver.

1) CD $HOME/Examples/TScirc/LHkarney. Type rundke and enjoy your first experience !

2) [optional] How to run matrix inversion with MUMPS (parallel or sequential processing). Read the $HOME/Packages/MUMPS/readme.txt file

3) the full code documentation is given in $HOME/Doc/NoticeDKE.pdf file. It corresponds to the reference
J. Decker and Y. Peysson. Dke: "a fast numerical solver for the 3-D relativistic bounce-averaged electron 
drift kinetic equation". Euratom-CEA report EUR-CEA-FC-1736, Association EURATOM-CEA sur la 
Fusion Controlee, Saint-Paul-lez-Durance, France, 2004.

4) the directory $HOME/Display contains all functions for displaying results
