For compiling mexfiles for PETSc, type the following commands when you are 
in the ~/PETSc/MEX/Bin/GNLX64 directory :

mex ../../Source/ReadBinaryArray_mex_c.c
mex ../../Source/writeBinaryArray_mex_c.c
mex ../../Source/writeBinaryIntArray_mex_c.c
mex ../../Source/writeBinarySparseMat_mex_c.c
mex ../../Source/writeBinaryTensor_mex_c.c
