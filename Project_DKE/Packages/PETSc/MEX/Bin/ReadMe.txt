For compiling mexfiles for PETSc, type the following commands when you are 
in the ~Project_DKE/PETSc/MEX/Bin directory :

mex ../Source/ReadBinaryArray_mex_c.c -v
mex ../Source/ReadBinaryIntArray_mex_c.c -v
mex ../Source/writeBinaryArray_mex_c.c -v
mex ../Source/writeBinaryIntArray_mex_c.c -v
mex ../Source/writeBinarySparseMat_mex_c.c -v
mex ../Source/writeBinaryTensor_mex_c.c -v
