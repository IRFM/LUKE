In the first order Drift-Kinetic equation, the diffusion and convection flux
elements related to $\widetilde{f}$ are bounce-averaged according to the
expressions (\ref{diffbavdkepp})-(\ref{convbavdkem}), which gives, using (%
\ref{elec}),
\begin{equation}
\widetilde{\Bbb{D}}_{\mathbf{p}}^{\text{E}(0)}=0
\end{equation}
and the convection components
\begin{eqnarray}
\widetilde{F}_{p}^{\text{E}(0)} &=&\sigma \left\{ \sigma \frac{\xi }{\Psi
\xi _{0}}q_{e}\xi E_{\Vert }\right\}  \\
\widetilde{F}_{\xi }^{\text{E}(0)} &=&-\left\{ \frac{\xi ^{2}}{\Psi
^{3/2}\xi _{0}^{2}}q_{e}\sqrt{1-\xi ^{2}}E_{\Vert }\right\}
\end{eqnarray}

Since the poloidal dependence of the electric field on a flux-surface is
given by relation (\ref{efieldpar})
\begin{equation}
E_{\Vert }\left( \psi ,\theta \right) =\frac{1}{\Psi \left( \psi ,\theta
\right) }\frac{R_{0}^{2}}{R^{2}}E_{\Vert 0}\left( \psi \right)
\end{equation}
we find
\begin{eqnarray}
\widetilde{F}_{p}^{\text{E}(0)} &=&\frac{\overline{\lambda }_{2,-2,2}}{%
\lambda }q_{e}\xi _{0}E_{\Vert 0}\left( \psi \right)  \\
\widetilde{F}_{\xi }^{\text{E}(0)} &=&-\frac{\overline{\lambda }_{2,-2,2}}{
\lambda }q_{e}\sqrt{1-\xi _{0}^{2}}E_{\Vert 0}\left( \psi \right)   \nonumber
\end{eqnarray}
where we defined the bounce averaged coefficient (\ref{lkm})
\begin{equation}
\overline{\lambda }_{2,-2,2}=\lambda \left\{ \frac{\xi ^{2}}{\xi _{0}^{2}}%
\frac{1}{\Psi ^{2}}\frac{R_{0}^{2}}{R^{2}}\right\}
\end{equation}
