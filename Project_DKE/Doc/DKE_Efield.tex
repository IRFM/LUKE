In the first order Drift-Kinetic equation, the diffusion and convection flux
elements related to $\widetilde{f}$  are bounce-averaged according to the
expressions (\ref{diffbavdke})-(\ref{convbavdke}), which gives, using (\ref
{elec}),  
\[
\widetilde{{\Bbb D}}_{{\bf p}}^{\text{E}(0)}=0
\]
and the convection components 
\begin{eqnarray}
\widetilde{F}_{p}^{\text{E}(0)} &=&\sigma \left\{ \sigma \frac{\xi }{\Psi
\xi _{0}}q_{e}\xi E_{\Vert }\right\}  \\
\widetilde{F}_{\xi }^{\text{E}(0)} &=&-\left\{ \frac{\xi ^{2}}{\Psi
^{3/2}\xi _{0}^{2}}q_{e}\sqrt{1-\xi ^{2}}E_{\Vert }\right\}   \nonumber
\end{eqnarray}

Since the poloidal dependence of the electric field on a flux-surface is
given by () 
\begin{equation}
E_{\Vert }\left( \psi ,\theta \right) =\frac{1}{\Psi \left( \psi ,\theta
\right) }\frac{R^{2}\left( \psi ,\theta _{0}\right) }{R^{2}\left( \psi
,\theta \right) }E_{\Vert }^{\left( 0\right) }\left( \psi \right) 
\end{equation}
we find 
\begin{eqnarray}
\widetilde{F}_{p}^{\text{E}(0)} &=&\frac{\lambda _{2,-2,2}^{P}}{\lambda }%
q_{e}\xi _{0}E_{\Vert }^{\left( 0\right) }\left( \psi \right)  \\
\widetilde{F}_{\xi }^{\text{E}(0)} &=&-\frac{\lambda _{2,-2,2}^{P}}{\lambda }%
q_{e}\sqrt{1-\xi _{0}^{2}}E_{\Vert }^{\left( 0\right) }\left( \psi \right)  
\nonumber
\end{eqnarray}
where we defined the bounce averaged coefficient (\ref{lkm}) 
\begin{equation}
\lambda _{2,-2,2}^{P}=\lambda \left\{ \frac{\xi ^{2}}{\Psi ^{2}\xi _{0}^{2}}%
\frac{R^{2}\left( \psi ,\theta _{0}\right) }{R^{2}\left( \psi ,\theta
\right) }\right\} 
\end{equation}
